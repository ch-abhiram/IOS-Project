# Memory Match – Card Game

## Description
Memory Match is a two-player iOS card matching game developed using Swift and Storyboard (UIKit). The goal is to find all matching pairs by flipping cards. It’s a simple, fun, and interactive way to improve short-term memory and enjoy light competition.

## Features
- Two-player mode on the same device
- Randomized card positions every game
- Real-time scoring and turn-switching
- Winner display and restart option
- Clean UI with storyboard-based navigation

## Requirements
- Xcode 15 or later
- iOS 17 or later
- Swift 5
